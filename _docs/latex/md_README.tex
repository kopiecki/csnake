Yet another \href{https://en.wikipedia.org/wiki/Snake_(video_game_genre)}{\texttt{ snake}} clone. Dead simple, no bells and whistles, made out of boredom.

\hypertarget{md_README_autotoc_md1}{}\doxysection{Dependencies}\label{md_README_autotoc_md1}

\begin{DoxyItemize}
\item {\ttfamily cmake} and {\ttfamily make} for building
\item {\ttfamily ncurses} for terminal stuff
\item \href{https://github.com/kopiecki/ncge}{\texttt{ ncge}} git submodule
\end{DoxyItemize}\hypertarget{md_README_autotoc_md2}{}\doxysection{Bulding}\label{md_README_autotoc_md2}
